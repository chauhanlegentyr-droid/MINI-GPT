# MINI-GPT

A self-contained Jupyter Notebook mini project for experimenting with GPT-style language model concepts and text generation.

> The project is distributed in `MINI_GPT_NIRBHAY-main.zip`; the notebook is located inside the archive at `MINI_GPT_NIRBHAY-main/nirbhay_66_mini_gpt.ipynb`.

## Contents

- `MINI_GPT_NIRBHAY-main.zip` — source archive containing the mini GPT notebook
- `README.md` — project documentation

## Getting Started

### 1. Download or clone the repository

```bash
git clone https://github.com/chauhanlegentyr-droid/MINI-GPT.git
cd MINI-GPT
```

### 2. Extract the notebook

```bash
unzip MINI_GPT_NIRBHAY-main.zip
```

### 3. Open the notebook

Install Jupyter Notebook, if it is not already available:

```bash
pip install notebook jupyter
jupyter notebook
```

Then open:

```text
MINI_GPT_NIRBHAY-main/nirbhay_66_mini_gpt.ipynb
```

You can also upload the notebook to Google Colab or Kaggle Notebooks and run the cells in order.

## Usage

1. Open the notebook in Jupyter, Google Colab, or another Jupyter-compatible environment.
2. Install or import the dependencies requested in the notebook.
3. Run each code cell sequentially from top to bottom.
4. Modify the configuration, training text, or prompt values as needed to experiment with text generation.

If the notebook requires a package that is not installed in your environment, install it with `pip` from a notebook cell:

```python
%pip install <package-name>
```
